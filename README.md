# Ground Truth Tool

A web-based mapping application for visualizing and managing ground truth data for Digos City.

## Features

- Interactive map visualization using Leaflet
- Display of barangay boundaries and locations
- Digos City boundary overlay
- Mock data integration for testing and development

## Files

- `index.html` - Main HTML entry point
- `app.js` - Application logic and map initialization
- `styles.css` - Custom styling
- `mock_data.js` - Mock data for testing
- `brgy_boundaries_location.json` - Barangay boundary data
- `digos-city-boundary.json` - City boundary data

## Usage

Simply open `index.html` in a web browser to run the application.

## Requirements

- Modern web browser with JavaScript enabled
- Internet connection (for loading map tiles and external libraries)
